    Intro

    Not much to recap this month.

    I've been looking at a lot of artwork so found a few artists that I'm going to keep up with.

    Continued work on my card site redesign. The Figma prototype is finished and I've started on the build. It's a lot of fun to actually see it start to come together, makes all the weeks of design stagnation feel worth it.

    I've abandoned tailwindcss for the build. If you're using a javascript component-based framework like React then tailwind's great - utility classes are super useful and your modular blocks of elements are contained really nicely. But if you're not using components then your page looks like a wall of mess that hurts to look at.

    Power to all the tailwind lovers, but for this project I'm trying out BEM and having a lot of fun doing it.

    Figured out a way to generate dynamic evolution trees consistantly using only CSS and I'm chuffed with it.
