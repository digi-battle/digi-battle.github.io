The website for the animation/VFX studio ZAM Studios is pretty neat. Particularly the homepage, which is an interactive animated scene that begins your navigation on the site. Like an old school splash screen. 

It's cool not only in style but in execution - this section is a canvas element that loops a frameset containing *the entire* scene, and that frameset changes depending on what elements are hovered to a set that shows that element's effect. Means there's only 24 images used to represent all possible interactions and they don't need to faff about with the positioning of each individual element. I never would've thought of that!
