Yuta Endo is a sonic UI/UX designer, which is something I've never really thought about. Sound plays a massive part in how an interface *feels*.

He describes this project as "A sonic reimagination of UI moments from the animated series Evangelion."

The sound design really captures the frantic nature of the scenes that feature these user interfaces.
